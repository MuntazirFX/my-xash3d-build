# XashFusion

> **Classic GoldSrc games. Modern iOS experience.**

XashFusion brings **Half-Life**, **Blue Shift**, **Opposing Force**, **Counter-Strike 1.6**, and **Counter-Strike: Condition Zero** to iPhone and iPad — with a modern iOS-native interface.

Built on top of the proven [Xash3D-FWGS](https://github.com/FWGS/xash3d-fwgs) engine.

---

## ✨ Features

- 🎮 5 Games — Half-Life, Blue Shift, Opposing Force, CS 1.6, CS: CZ
- 📱 iOS-native SwiftUI launcher
- 🎯 Touch controls with left/right-handed layouts
- 🔊 3D positional audio
- 🎛️ Advanced settings (graphics, audio, input)

## 📥 Installation

1. Download `.ipa` from [Releases](../../releases)
2. Sideload with Sideloadly / AltStore / TrollStore
3. Copy your legally-owned Steam game files into `Files → XashFusion → Documents/`
4. Launch from the app

## ⚠️ Legal

No copyrighted game assets are bundled. Users must provide their own legally-obtained game files.
